# Smartphone Recommendation Web App

A responsive smartphone recommendation web application built using PHP and object-oriented programming. Users can browse smartphone listings, filter by preference, and leave reviews. The site uses JSON for data management and Bootstrap 5 for styling and layout.

---

## Features

- Object-Oriented PHP structure
- Smartphone listing page with filters
- User reviews and rating system
- Pagination for large datasets
- Responsive layout using Bootstrap 5
- Clean, modular file organization

---

## Tech Stack

- PHP (OOP)
- HTML, CSS, Bootstrap 5
- JavaScript
- JSON for data handling
- Apache via UniServerZ (local dev)
